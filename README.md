# C-Data-Structures
Implementations of common Data Structures, like Linked Lists and Dynamic Arrays using raw C Language.

## Existing Contents
- Linked List
- Circular Linked List
- Doubly Linked List
- Array Stack
- Linked List Stack
- Array Queue
- Circular Array Queue
- Linked List Queue
- Binary Search Tree

## Run Commands
- `make`: compiles code.
- `make run`: runs compiled code.

## Console Tests
I have performed some tests in the main.c file by importing the header files I had written. When you compile and run, you may observe test results.
